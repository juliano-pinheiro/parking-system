Por que esta página é exibida aqui?
Hospedagem Estática (GitHub Pages) vs Aplicação Backend (Render / Servidor Python)

O GitHub Pages é um serviço voltado exclusivamente para páginas estáticas (HTML, CSS e JS). Como este sistema foi construído em Python (Flask) com banco de dados Supabase (PostgreSQL), rotas de API protegidas e emissão de sessões criptografadas, ele precisa rodar em um servidor web como o Render.

Anteriormente, o GitHub Pages exibia o arquivo README.md como texto porque não encontrava uma página principal configurada. Agora, você pode acessar a aplicação ativa diretamente pelo botão abaixo ou configurando a URL do seu servidor.

Módulos e Recursos Profissionais

Tudo o que você precisa para gerenciar estacionamentos de pequeno, médio e grande porte.

Operação de Pátio & Entrada

Controle instantâneo de veículos em permanência com monitoramento de vagas e tempo acumulado.

  • Placa no padrão Mercosul com máscara
  • Categorias: Carro, Moto, Camionete, Grande
  • Hero banner com ocupação e lotação em tempo real
  • Bloqueio mandatório quando o caixa estiver fechado

Checkout de Saída & Recibos

Cálculo tarifário automático e emissão rápida de comprovantes para impressoras térmicas.

  • Pré-cálculo com base no tempo de permanência
  • Calculadora integrada de troco para dinheiro
  • Impressão em bobinas térmicas de 80mm ou 58mm
  • Ticket perdido com liberação automática de vaga

Controle de Caixa & Turnos

Acompanhamento rígido do fluxo diário com suporte a múltiplos operadores e formas de pagamento.

  • Abertura com valor inicial (fundo de troco)
  • Sangria e Suprimento com justificativa
  • Fechamento com conferência cega e diferença
  • PIX, Dinheiro, Cartões, Convênios e Mensalistas

Dashboard Financeiro & KPIs

Cockpit analítico para tomada de decisão gerencial com gráficos dinâmicos e comparativos.

  • Receita do Dia, Mês, Ano e Ticket Médio
  • Evolução temporal: Diário (30d), Mensal e Anual
  • Mix de meios de pagamento em gráfico Donut
  • Curva de fluxo por horário com badge de horário de pico

Acesso Mobile & Terminal POS

Operação portátil para manobristas e operadores de pátio diretamente do celular.

  • QR Code gerado na tela com IP da rede local Wi-Fi
  • Barra inferior rápida (Bottom Bar) para toque
  • Mapa visual de vagas livres e ocupadas
  • Compatível com coletores POS Android e smartphones

Multi-Empresa & Permissões

Isolamento completo dos dados por CNPJ e controle granular de acessos por função.

  • Multi-CNPJ com alternador rápido de filial
  • Perfis de acesso: Administrador, Supervisor, Operador
  • Trilha completa de auditoria com exportação CSV
  • Emissão de NFSe e controle de mensalistas inadimplentes
Deploy Gratuito

Como colocar o Sistema Online no Render

O repositório já está 100% pronto com o arquivo render.yaml para deploy automático gratuito.

1

Crie sua conta no Render

Acesse render.com e faça login gratuitamente com sua conta do GitHub.

2

Conecte o Repositório

No painel do Render, clique em New + → Blueprint e selecione o repositório parking-system.

3

Configure o Supabase

Informe as variáveis de ambiente SUPABASE_URL e SUPABASE_KEY no painel. O Render iniciará a aplicação automaticamente com link HTTPS!
